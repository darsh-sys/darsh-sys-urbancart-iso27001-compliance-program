# UrbanCart – ISO 27001 Compliance Program

A self-directed GRC portfolio project simulating the build-out of a
baseline information security compliance program for a fictional small
e-commerce company, UrbanCart (10 employees).

## 📌 Project Overview
UrbanCart sells home and lifestyle products through its own online store,
using Shopify, Stripe, Google Workspace, and AWS S3. This project simulates
a compliance officer's work: identifying assets, mapping ISO 27001 Annex A
controls, assessing gaps, and recommending remediation steps.

## 📁 Contents
- `spreadsheets/UrbanCart-Compliance-Matrix.xlsx` – Asset list + 12 mapped
  ISO 27001 controls with status, ownership, and remediation actions
- `Docs/UrbanCart-ISO27001-Compliance-Summary.pdf` – 1-page written gap analysis
  and recommendations

## 🔍 Key Findings
Out of 93 controls in ISO 27001 Annex A, 12 relevant controls were selected
and reviewed for UrbanCart's size and setup:
- **5** Not Implemented
- **7** Partially Implemented
- **0** Fully Implemented

High-priority gaps: no written security policy (A.5.1), no security
awareness training (A.6.3), no vulnerability management process (A.8.8),
and unencrypted AWS S3 storage (A.8.24).
